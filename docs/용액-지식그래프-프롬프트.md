# 용액 지식그래프 만들기 — 간단 프롬프트

> Gemini · Claude · ChatGPT 웹 어디에 붙여넣어도 됩니다.
> 아래 블록을 통째로 복사 → 맨 아래 `[표 붙여넣기]` 자리에 학생 응답을 넣고 전송.

---

아래 표는 5학년 학생들이 **"우리 주변의 용액과 그것을 찾을 수 있는 곳"**을 적은 거야.
이걸 **지식 그래프(knowledge graph)**로 만들어줘.

규칙:
1. 같은 뜻은 하나로 합쳐줘. (예: `CU`=편의점, `우리집 냉장고`·`냉장고`=냉장고, `우리집 주방`=주방)
2. 관계(화살표): **`[용액]` → `[찾을 수 있는 곳]`**
3. 상위 범주로 묶어줘.
   - 장소 → (집 / 상점 / 자연)
   - 용액 → (과일음료 / 차 / 생활용품 / 기타) 처럼 적당히
4. 출력은 **Mermaid `graph LR` 문법**으로. (mermaid.live 에 붙여 바로 볼 수 있게)

[표 붙여넣기]
용액, 찾을 수 있는 곳
포도즙, 우리집 냉장고
물, 내 물통
사이다, 왕십리역
바닷물, 바다
가글, 우리집 화장실
2프로 음료수, CU
간장, 이마트
바나나 우유, 편의점
커피, 카페
...

---

## 선택 옵션 (필요할 때 규칙에 한 줄 추가)

- **과학 개념 점검까지:** "각 항목이 진짜 *용액*(용질이 녹아 균일한 혼합물)인지 표시해줘. 아니면 이유도 한 줄로. (예: 바닷물=O, 바나나우유=균일하지 않음)"
- **워드클라우드용 빈도:** "용액·장소별로 몇 명이 적었는지 횟수도 같이 세줘."
- **JSON으로 받기(앱에 넣을 때):** "Mermaid 대신 `{ nodes:[{id,label,type}], edges:[{source,target,relation}] }` JSON으로 출력해줘."
