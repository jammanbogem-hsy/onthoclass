## 적용

`glass-surface.tsx`에서 화면 크기에 맞는 물리 굴절 맵을 생성하는 공개 커널을 사용한다. 탐색 바, 물방울, 공방의 대화·제작 카드, 에셋 카드, 월드 편집 패널, 플레이 도구 막대가 유리 표면이다. 마우스 위치에 따라 반사광이 달라지며 글자·입력은 굴절 층 위에서 선명하게 유지한다.

Chromium에서는 배경이 실제로 휘어진다. Safari·Firefox에서는 커널의 자동 판정으로 반투명 유리 효과를 사용한다. 색수차는 교실 기기의 렌더링 부담을 줄이기 위해 끈다. 대비 증가·투명도 감소 설정에는 불투명한 작업 표면을 제공하고, 동작 감소 설정에서는 반사광 이동과 전환을 줄인다.

## 학생용 화면

- 장식용 영문 부제, 모델명, API 키 상태, 성능 표시를 제거했다.
- 첫 화면의 두 진입점을 학생 입장·선생님 공방 개설로 설명한다.
- 제작 카드에는 이름·설명·종류를 먼저 보인다. 크기·검색 단어는 접어서 제공한다.
- 검색 단어를 생략하면 이름으로 자동 지정한다. 바닥 종류를 고르면 기본적으로 지나갈 수 있게 설정한다.
- ‘스페이스’는 ‘월드’, ‘PIN’은 ‘숫자 비밀번호’, ‘탑뷰/아이소’는 ‘위에서 보기/입체로 보기’로 표현한다.
- 공용 에셋 등록, 관리자 삭제, 인물 아바타, 투명 배경 그림 다운로드 흐름을 유지한다.

검증은 기존 Firebase 에뮬레이터 통합 테스트·전체 제작 흐름 브라우저 테스트와 함께, 실제 픽셀 변화로 굴절 효과와 고대비 대체 표면을 확인한다.

## 탐색과 메인 화면 보완

- 에셋 공방·브랜드 링크에 `view=workshop`을 명시했다. 정적 내보내기에서 다른 화면으로 이동한 뒤 검색 매개변수가 없는 링크를 누르면 현재 화면이 유지되는 문제를 재현하고 수정했다.
- 내 월드의 소개·예시·최근 작업 카드와 새 월드 대화상자를 실제 변위 맵을 쓰는 표면으로 바꿨다. 미리보기 렌더러에 선택적 투명 배경을 추가해 불투명한 회색 사각형을 없앴다.
- `GlassButton`·`GlassLink`는 작은 크기에 맞춘 굴절 강도 38·가장자리 폭 9의 렌즈를 사용한다. 안쪽의 원래 HTML 버튼·링크가 전체 표면을 채우며 폼 전송·다운로드·키보드·비활성 상태를 담당한다.
- 카드의 물리 반사광과 겹치던 CSS 흰 테두리를 제거했다. 넓고 평평한 파란 띠 대신 부드러운 깊이와 가는 반사광을 가진 배경을 구성했다.
- 브라우저 회귀 검증에 내 월드·에셋 모음·편집기에서 공방으로 돌아가기, 키보드로 새 월드 만들기, 모바일 터치 탐색, 메인 카드 변위 맵을 끄기 전후 픽셀 비교를 포함했다.

## 플레이 화면의 버튼

맵 위에서는 유리 막대 안에 버튼 렌즈를 중첩하지 않는다. 도구 막대에 낮은 굴절·중립 채도·읽기용 서리를 한 번 적용하고, 안쪽에는 테두리 없는 HTML 버튼·링크와 아이콘을 배치한다. 같은 월드·맵 이름은 한 번만 표시하며 서로 다른 이름만 두 줄로 표시한다. 긴 이름은 버튼 공간을 확보한 뒤 말줄임한다.

편집·나가기·시점 전환·품질 전환·말 걸기·안내판·퀴즈의 조작 스타일을 맞췄다. 모바일에서는 도구 막대를 두 줄로 배치하고 키보드 안내를 숨긴다. 대화 중에는 조이스틱과 말 걸기 버튼을 숨겨 대화창과 겹치지 않게 한다. 모든 주요 조작에는 최소 44px 높이를 확보한다.

게임 단축키는 HTML 컨트롤에 포커스가 있을 때 Enter·Space를 가로채지 않는다. `play-controls.test.cjs`는 저장된 샘플 월드에서 편집·나가기, 시점 변경, 키보드 품질 전환, 긴 제목의 모바일 배치, 안내판 열기·닫기, 퀴즈 응답을 검증한다. 테스트는 새 브라우저의 로컬 월드와 모의 공방 상태만 사용한다.
